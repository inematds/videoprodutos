🎬 videoprodutos

Fonte dos produtos

Uma pasta (cada subpasta = um produto com fotos + produto.json/md opcional; ou fotos soltas = um produto por foto) ou a URL de uma loja/página (Shopify, WooCommerce, JSON-LD, OpenGraph ou imagens da página).

Lote (várias tarefas)

Uma fonte por linha. Campos opcionais separados por |: preset, estilo, formato (16:9, 9:16, ambos), max=N, marca=Nome, sem-video. Linhas com # são ignoradas.

Serviços

verificando…

Tudo roda local e sem custo. LLM e imagem por IA são opcionais — veja Configurações.

Fila de produção

Projetos gerados

Configurações

Salvas em .env na pasta do projeto (chaves ficam só no seu disco). Defaults = tudo local e grátis. Deixe em branco para voltar ao padrão.

Como funciona

  1. Busca os produtos na pasta ou na URL (baixa fotos, nome, descrição e preço quando existem).
  2. Classifica o produto (tecnologia, moda, alimento, casa…) e escreve o copy (título, 3 benefícios, CTA) — com LLM local (Ollama) ou por template.
  3. Imagens: recorta o fundo (rembg local) e recompõe no preset escolhido — ou automático pela categoria — em 1:1, 16:9 e 9:16, versões limpa e com texto/preço.
  4. Vídeo: intro → benefícios → oferta/CTA, com zoom, transições, grade de cor por estilo, música CC0 (Freesound via inemavox) e narração opcional. Sai 16:9 e 9:16 + um catálogo com todos os produtos.
  5. Tudo é salvo em <saída>/<projeto>/ com projeto.json.

Formato da pasta

produtos/
  fone-x1/            ← um produto
    1.jpg 2.jpg
    produto.json      ← {"name":"Fone X1","price":"R$ 199","desc":"...","category":"tecnologia"}
  caneca-azul/
    foto.png
    produto.md        ← 1ª linha = nome, resto = descrição
  camiseta.jpg        ← fotos soltas: um produto cada

CLI

node cli.js ~/produtos --preset dark-premium --estilo tech
node cli.js https://loja.com.br --max 5 --formato 9:16
node cli.js --lote lista.txt
